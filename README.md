# Аналитика продаж для компании Northwind (SQL)

Проект посвящен анализу бизнес-показателей торговой компании с использованием СУБД PostgreSQL. Это мой первый практический кейс в рамках формирования портфолио дата-аналитика.

## Что было сделано:
* Анализ выручки: определены ТОП-3 самых прибыльных товаров компании.
* Логика скидок: с помощью оператора CASE WHEN данные были сегментированы по величине скидок. Выявлено, что продажи без скидки принесли наибольшую выручку.
* VIP-клиенты: написан сложный запрос с тройным INNER JOIN для выявления ключевых контрагентов.

## Ключевые инсайты:
1. Лидером по закупкам стала компания QUICK-Stop с общей суммой покупок более 117 тыс. долларов.
2. Скидки более 10% генерируют большой объем выручки, но требуют контроля маржинальности.

*Весь чистый код проекта находится в файле pet.project.sql в этом репозитории.*
